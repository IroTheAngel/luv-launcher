Repertoire Trainer

WebsiteWindowsAndroid

Learn a whole chess opening repertoire with a coach that talks you through every move. Nearly 500 lines for White and Black (Catalan, Queen's Gambit, Vienna, Caro-Kann, Sicilian and more), plus puzzles, a daily streak, XP and games against the computer.

Open Windows 2 MB Android 0.3 MB
How to install the apps
Windows
  1. Open RepertoireTrainer-Setup.exe. It installs itself and adds a desktop shortcut.
  2. If Windows says it protected your PC, click More info, then Run anyway.
Android
  1. Open RepertoireTrainer.apk on your phone.
  2. If Android asks, let your browser install unknown apps, then tap Install.
Bring your progress
  1. On the website's home page, use Back up or move progress, then load the backup in the app.

Schedule Maker

AndroidWindowsWebsite

A daily and weekly planner. Add tasks with times, let Claude turn piano and study sessions into timed blocks, and start Focus mode with rain or wave sounds. On Android, Focus mode also blocks YouTube, TikTok and other distracting apps.

Android 3.5 MB Windows 121 MB Open in browser
How to install
Android
  1. Open ScheduleMaker.apk on your phone. If Android asks, let your browser install unknown apps, then tap Install.
  2. The first time you press Focus, turn on Usage access and Display over other apps for Schedule Maker, so it can block apps.
  3. New versions install over the old one and keep your schedule.
Windows
  1. Open ScheduleMaker-Setup.exe. If Windows says it protected your PC, click More info, then Run anyway.

Free Game Review

Chrome extensionchess.com

Review your finished chess.com games as often as you like, for free. Stockfish 18 runs in your own browser and rates every move from Brilliant to Blunder, with accuracy, an evaluation graph, a coach that explains each move, and a mode to practise your mistakes.

Download ZIP 6 MB GitHub
How to install
  1. Unzip the download somewhere you'll keep it, like Documents. Chrome runs the extension from that folder, so don't delete it.
  2. In Chrome, open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped folder (the one with manifest.json in it).
  4. Pin it from the puzzle-piece menu, then click Free Review when a game ends on chess.com.

Eretz Ir ארץ עיר

WebsiteAndroidHebrew

A helper for the classic Hebrew categories game. Spin the wheel for a random letter, then everyone writes a country, a city, an animal and more that start with it. It has a turn timer, a dictionary with hints when you're stuck, and a score table for the week.

Play Android 1 MB
How to install on Android
  1. Open EretzIr.apk on your phone. If Android asks, let your browser install unknown apps, then tap Install.
  2. The app opens inside Chrome, so Chrome needs to be installed.

PULSE

PCPythonPygame

A dark dungeon game where you can only see by sending out pulses that light up the walls. Every pulse drains your battery and makes noise that enemies can hear. Open chests, go down 8 floors and beat The Manager. It also has an AI that learns to play the game by itself.
