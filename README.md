# Luv Launcher

Open, install and launch everything I've made, from one place: https://irotheangel.github.io/luv-launcher/

Get the app (it installs and launches the apps for you):

- **Windows:** [LuvLauncher-Setup.exe](https://github.com/IroTheAngel/luv-launcher/releases/latest/download/LuvLauncher-Setup.exe). If Windows says it protected your PC, click **More info**, then **Run anyway**.
- **Android:** [LuvLauncher.apk](https://github.com/IroTheAngel/luv-launcher/releases/latest/download/LuvLauncher.apk). If Android asks, let your browser install unknown apps, then tap **Install**.

What's inside:

- **Repertoire Trainer**: chess opening trainer with a spoken coach (website, Windows, Android)
- **Schedule Maker**: daily and weekly planner with focus mode (Android, Windows, website)
- **Free Game Review**: Chrome extension that reviews finished chess.com games with Stockfish
- **Eretz Ir**: Hebrew letter-spinner for the categories game (website, Android)
- **PULSE**: dark dungeon game in Python

The website and both apps use the same page, `index.html`. Button icons are from Free Icon Pack v3.1 by @gvesster.
